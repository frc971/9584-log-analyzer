# Instructions for AI agents (Codex and others)

The instructions for this repo are in [GEMINI.md](GEMINI.md). Read it first and follow it: the
name is historical and it applies to every agent. Gemini CLI reads GEMINI.md by itself, Claude Code
reads CLAUDE.md (which imports it), and Codex reads this file.

The standard tasks are in [AGENT_TASKS.md](AGENT_TASKS.md): **report**, **module**, **vision** and
**compare**. Gemini and Claude Code have them as `/report`, `/module`, `/vision`, `/compare`.
Students using another agent ask in words, for example "do the report task on
logs/akit_..._q68.wpilog" or just "give me the full report for q68": read AGENT_TASKS.md and follow
that task exactly.
